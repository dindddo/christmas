# 2막 기획안 — 「노엘이 지켜본 너의 1년」 (결제 후, 3,900원)

## 2막의 가치
한 줄: **1막이 던진 떡밥을 하나도 빠짐없이 회수하고, 그날 내가 실제로 알아보고 움직일 수 있을 만큼 구체적으로 알려준다.**

1. **서사에서 깔아놓은 기대감을 충족**
2. **더 디테일하게 궁금해야 할 지점을 만족**
3. (제안) **간직하고 다시 오게 만드는 가치** — 공유 카드, 12/24 알림, 그날 이후 "알아봤어?" 확인 → 바이럴과 3막(굿즈·다음 해)으로 연결

### 1. 1막 떡밥 → 2막 회수
| 1막에서 깐 떡밥 | 유저 기대 | 2막에서 갚는 방법 |
|---|---|---|
| "딱 한 사람에게만 선물을 줘" (P4) | 그 선물이 뭔데? | 선물 = 알아보는 눈. 열쇠를 꽂는 순간 2막 전체가 그 선물임을 보여줌 |
| "그 사람이 곁을 지나가는 순간, 알아챌 수 있게" (P5) | 정말 알아챌 수 있어? | 알아보는 신호 3가지 |
| "몇 번이나 문 앞까지 왔다가 그냥 지나친 사람" (P6) | 내가 뭘 놓쳤지? | 올해 놓친 장면 회수 ("3월 그 연락, 그게 신호였어") |
| "이번엔 선물만 두고 가지 않기로 했어" (P7) | 노엘이 직접 뭘 해주지? | 그날의 미션, 12/24 아침 알림 (동행감) |
| "아무한테나 주는 건 아니라서" (채팅) | 왜 나야? | 사주 근거로 "네 팔자에 이게 있어서" |
| 블러 얼굴·첫마디·성격 뒷부분 | 다 보여줘 | 전부 공개 (하나라도 남기면 낚시) |
| "문 열리는 날? 딱 하루야." | 정확히 언제·어디? | 날짜, 시간대, 장소 확정 |

### 2. 디테일 궁금증 지도
| 질문 | 2막의 답 | 근거 |
|---|---|---|
| 누구? | 얼굴, 나이대, 직업, 성격 전체, 첫마디 | 연애 기운(관성·재성) 오행과 자리 |
| 왜 이 사람? | 맞물리는 지점 1, 부딪힐 지점 1 | 두 일간의 상생·상극 |
| 언제? | 12/8~24 달력, 문 열리는 날, 시간대, 흔들릴 날 | 일진 점수, 시진 |
| 어디서? | 장소 3곳 (1순위 + 대안) | 오행별 장소, 직업 맥락 |
| 어떻게 알아봐? | 신호 3가지 (말투, 겹치는 패턴, 내 반응) | 상대 오행 성향 |
| 그날 뭘 해야 해? | 미션 3개, 피할 행동 1개 | 내 원국 약점 보완 |
| 잘 될까? | 이어질 가능성과 조건 ("이렇게 하면 열려") | 대운, 2027 흐름 |
| 내 고민은? | 고민에 대한 노엘의 답 | WORRY 표 |

연애 상태별 무게: 솔로(누구·어디), 썸(맞아?·언제 말해?), 이별(다시 와?·새 사람?), 연애·결혼(그날 둘에게 무슨 일?). 같은 뼈대에 섹션 순서·문구만 분기.

## 2막 구성
| 장 | 내용 | 일반 사주 앱 | 차별점 |
|---|---|---|---|
| 0. 문이 열림 | *철컥.* "약속했지. 이제 다 보여줄게." | 결과 나열 | 열쇠 연출로 서사 연결 |
| 1. 2026 되돌아보기 | 월별 장면, 연애·일·사람·돈 4갈래, 놓친 신호 | "상반기 운이 좋았습니다" | 노엘 1인칭 관찰("내가 지켜본 너의 3월은…") + "그때 그게 신호였어" |
| 2. 남은 날들 (11/22~12/31) | 주별 흐름, 문 열리는 날, 흔들릴 날 | 월운 한 줄 | 날짜 단위 달력에 '알아볼 순간' 표시 |
| 3. 운명의 상대 + 알아보는 법 | 얼굴, 첫마디, 성격, 신호 3가지, 장소 | 이상형 설명 | 블러 공개 + 알아보는 신호로 철학 회수 |
| 4. 2027까지 이어지는 것 | 2027(丁未) 분기별 연애·일·변화, 올해 시작돼 내년에 열매 맺는 것 | 신년운세 별도 판매 | 올해 → 내년을 한 줄로 연결 |
| 5. 너의 본질적인 매력 | 끌리는 이유, 장점 3개, 너도 모르는 매력 1개 | 성격 나열 | 1막 문패 "들어봤을 말" 심화, "너도 몰랐던 너를 알아보게" |
| 6. 개운 포인트 | 부족한 기운, 막히는 패턴, 채우는 법 | "빨간색이 좋습니다" | 12월 미션 체크리스트(할 것 3, 피할 것 1) + 행운 색 = 개운 오너먼트(굿즈) |
| 7. 노엘의 편지 | 노엘이 쓴 크리스마스 편지 | 없음 | 저장·공유용. 마지막 줄 "알아보는 건, 결국 네 몫이야." |
| 8. 선물 | 연말 결산 카드(스토리용), 친구에게 문 열어주기, 12/24 알림, 오너먼트 | — | 공유·재방문 |

## 차별점 4가지
1. **관찰자 서사** — 1년 내내 창문 너머로 지켜본 노엘이 들려주는 이야기. 맞는 말이 "분석"이 아니라 "들킨 느낌"이 된다.
2. **'알아보는 눈'으로 관통** — 지난해: 놓친 신호 / 남은 날: 그 순간 / 운명의 상대: 그 사람 / 매력: 나 / 개운: 나를 알아보게 만드는 법.
3. **입력값 개인화** — 연애 상태, 직업, 고민으로 장마다 문장 분기.
4. **개운을 행동과 물건으로** — 미션 체크리스트와 개운 오너먼트로 행동·매출 연결.

## 원칙
- 1막에서 잠근 것은 2막에서 전부 공개.
- 같은 사람은 몇 번을 열어도 같은 결과(사진·장면도 사주로 고정 선택).
- 장소는 공공장소만, 단정 대신 "~일 확률이 높아".
- 분량: 1막의 2~3배, 스크롤 5~7분. 각 장 끝 노엘 한 줄로 다음 장 연결.
