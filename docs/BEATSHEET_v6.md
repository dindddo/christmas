## 0. 톤: "다정하게 위험한 남자"

커밋된 대사는 **위로**(수고했어, 다 보고 있었어, 편지)가 축이다. 여기에 귀여움(당황·귀 붉어짐)을 빼고 **여유·거리·목소리**로 긴장감을 얹는다.
말은 다정하게, 행동은 위험하게.

| | 하지 않는다 | 한다 |
|---|---|---|
| 노엘의 반응 | 당황, 귀 붉어짐, 핑계 | 여유. 웃음을 아낌. **흔들리는 건 너** |
| 말 | 설명, 긴 고백 | 짧고 낮게. 두 가지로 읽히는 말 |
| 거리 | 한 번에 확 다가감 | 장마다 한 칸씩: 맞은편 → 옆자리 → 의자를 당김 → 귓가 → 한 뼘 |
| 스킨십 | 노출, 키스, 쓰다듬기 | 손끝이 스침, 손을 늦게 놓음, 턱 끝을 드는 손가락, 귓가 |
| 의상 | 단정한 정장 | 검은 정장, 풀린 보타이, 셔츠 단추 두 개, 걷어 올린 소매 |

공간·조명: 전부 **"문 너머의 방"** 하나(촛불 연회장, 원탁, 트리, 눈 내리는 아치형 창). 변신 전 = 금빛 촛불 / 변신 후 = 같은 방에 달빛 은청색.
수위 기준: 1막은 결제 전(만 19세 확인 전)·공유 썸네일·메타 광고 노출 → **노출·키스 없음**. 광고용 컷은 따로 수위를 낮춘다.
