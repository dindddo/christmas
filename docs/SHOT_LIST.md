# 컷 설계서 v3 (2026-11-22)

생성 전에 이 문서로 컷마다 확인받는다. **확인(✅) 표시된 컷만 생성한다.**
파일명은 `lib/flow/flow.ts`·`content/prologue.ts`가 실제로 읽는 이름(`public/img/<이름>.jpg`) 기준.

## 공통

- 그림체: v3 원본 기준 입체감 있는 반실사(영화 장면풍). 원본 = `assets/master/v3/` (노엘 인간·천사, 너)
- 노엘: 프롤로그~채팅~로딩은 **인간(날개 없음)**, 1막 정체 공개(`angel`)부터 **천사(하얀 날개, 눈 빛남 금지)**
- 너: 가냘픈 체형, 긴 생머리, **얼굴 절대 안 보임**(뒷모습·어깨 너머·머리카락·손만). 실내는 검은 오프숄더 미니 원피스, 야외는 그 위에 긴 코트
- 수위 표시: **[광고OK]** 노출 없음(광고·썸네일에 써도 됨) / **[서비스]** 관능적, 서비스 안에서만
- 레퍼런스 표기(사용자가 준 이미지, 구도만 참고): 하숙생(키 차이 내려다봄) · 파멸적(몸 숙여 가둠) · 환승(손 잡아 올림·백허그·달빛 커튼) · 키스직전(위에서 이마 닿을 듯) · 블라인드(줄무늬 빛, 직진 응시) · 흑백(옆모습 턱 들기) · 홍조(당황, 손등으로 입 가림) · 볼터치(어깨 너머, 볼에 손) · 소애보(백허그)
- 진행 방식: 1k 시안 2장(3) → 고른 컷 부분 편집(1.5, 필요시) → 4k 업스케일(2) ≈ **컷당 5~7크레딧**
- 손이 크게 나오는 컷은 손 단독 클로즈업으로 분리. 두 사람 컷은 동작 하나만.
