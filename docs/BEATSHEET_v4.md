# 비트 시트 v4 — 거리가 좁혀지는 구조 (2026-11-24 초안)

> 목적: "사주 결과가 궁금해서"가 아니라 **"노엘 때문에" 사고 싶게** 만든다.
> 이 문서가 확정되면 → 대본 반영(content/*.ts) → 컷 목록 확정 → 새 얼굴로 이미지·영상 제작.

## 0. 원칙 4개

1. **거리 사다리** — 질문 하나, 결과 하나마다 노엘과의 물리적 거리가 한 칸씩 줄어든다. 이미지는 "포즈"가 아니라 "거리 변화"를 보여준다.
2. **결제 = 닿기 직전** — 감정 곡선의 꼭대기(이마가 닿기 직전)에서 멈추고, 그 다음을 문 너머(2막)로 넘긴다.
3. **결제 이유는 하나로** — "그 사람 얼굴"과 "노엘이 하고 싶었던 말"이 **같은 문 너머**에 있다. 노엘은 너를 그 사람에게 보내야 하는 천사 → 금지된 감정이 긴장을 만든다.
4. **수위는 설렘까지** — 스킨십은 손끝·날개·이마 직전까지. 키스·노출 없음(act2.ts 노엘 역할 규칙과 동일).

지켜야 할 기존 규칙: 프롤로그·채팅에 "천사" 금지 / 확인형 말투("~했지?") 금지 / 가짜 후기·이용자 수·할인 금지 / 빛나는 눈 금지.
