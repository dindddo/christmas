# 기능 명세 — 크리스마스에 운명의 문을 열어 버렸다

기준: `prototype/index.html` (claude.ai 랜딩 시안 Version 58). 문구가 이 문서와 시안이 다르면 **시안이 정답**.

## 0. 핵심 철학
인연은 오는 게 아니라 **알아보는 것**. 인연은 늘 먼저 와 있고, 알아보는 게 늦을 뿐.
노엘의 선물 = "그 사람이 곁을 지나가는 순간을 알아챌 수 있게" 해 주는 것 → 1막 사주풀이가 곧 그 선물.

## 1. 전체 흐름
| # | 단계 | 노엘 모습 | 유저 행동 |
|---|---|---|---|
| 0 | 타이틀 (로고, "크리스마스 전, 딱 한 번 열리는 문") | — | [노엘과 사주 보기] |
| 1 | 프롤로그 P1–P7 (세로 웹툰 오버레이, 건너뛰기 있음) | 목소리만 | 스크롤 |

## 3. 채팅 입력 (QS 배열)
1. "앉아. 오래 걸리진 않아." / "나는 노엘. 내가 뭔지는… 곧 알게 될 거야." / "너한테 줄 게 있어. 근데 아무한테나 주는 건 아니라서." → [뭔데?]
2. "그건 아직 비밀." / "네가 받을 사람이 맞는지, 확인부터 해야 하거든." / "우선… 널 뭐라고 부르면 돼?" → 이름 입력
3. "{이름}." / "이름 듣고 나니까 조금 보이네." / "근데 인연은 방향이 있거든. 넌 어느 쪽이야?" → 여자/남자
4. "좋아. 이제 좀 더 깊이 볼게." / "네 인연은 네가 태어난 순간에 이미 적혀 있어." / "{이름}, 언제 태어났어? 시간까지." → 양력/음력(+윤달), 년·월·일, 시각, 시간 모름
5. "요즘 네 옆엔, 누가 있어?" → solo 아무도 없어요 / crush 마음 가는 사람이 있어요 / partner 만나는 사람 있어요 / breakup 얼마 전에 헤어졌어요 / married 결혼했어요
6. "취향은? 결과가 달라지니까 잘 골라." → hetero / queer
7. "무슨 일 해?" → student / seek / office / biz / free / rest
8. "마지막. 제일 궁금한 거 하나만 골라." → 고민 선택지(WORRIES)
9. "…알겠어. 잠깐만." → 로딩

## 4. 로딩
"…됐어. 다 봤어." → "역시, 너 맞네." → "아까 내가 뭔지 궁금했지?" → **"이제 숨길 필요 없겠다."** → (변신 영상 T1: 인간 s0 → 천사 angel.jpg, 하얀 날개 촤악) → 1막

## 5. 1막 순서 (천사 노엘)
1. 천사 등장 컷 angel.jpg: *촤악—!* *사르륵* / "나는 인간의 인연을 돌보는 천사, 노엘." / "올해 선물, 너한테 줄게."
2. book_w.jpg "자, 펼쳐볼게." / "{이름}, 네 이야기."
3. 생년월일·절기·시진(+보정 안내) → 여덟 글자 → "…와." / "보통 팔자가 아닌데?" → 희소성 한 줄(FREQ, 100명 중 N명)
4. "흠." / **"한 줄로 말해줄게."**
5. 문패 카드: 물상, "좋아했던 사람한테 이런 말, 들어봤을 거야"(HEARD/HEARD_LOVE), 속마음, 연애할 땐, 올해, 여덟 글자 표, 오행 막대, 오행 한 줄, 격·강약(게이팅)
6. 年 너의 올해 카드 (closed.jpg 패널): 해의 제목 + 월별 장면 2~3개(가장 큰 장면 표시) + "그리고 지금, 12월. 그 장면들은 전부, 이번 겨울의 예고편이었어." (연애중/결혼: "둘의 다음 장이 시작될 차례야.")
7. 예고 비트 → 日 last_w.jpg → "너… 12월 N일에 문 열린다." 또는 "올해는 안 열려" → resA_w/resB_w + 날짜·장소·흔들릴 날 카드 + 범산식 풀이 문단(READ)
8. "그래서. 열쇠, 준비됐어?" → lock_w.jpg + 목차(TOC)
9. "12월 8일부터 24일까지 17일을 하루씩 다 봤어" / "문 열리는 날? 딱 하루야."
10. 緣 운명의 상대 카드: 블러 얼굴(fm/ff.jpg; 남성 이성애→ff, 여성 이성애→fm, 동성→같은 성별) + 나이(N~M년생, 차이) + 직업 + 만나는 장소 + 시기 + 성격(뒷부분 블러) + 첫마디(블러). 연애중/결혼은 '그날의 두 사람' 카드.
11. "얼굴까지 보고 싶으면, 열쇠 꽂아." → 결제 CTA

### 운명의 상대 나이 규칙
연애 기운이 처음 나오는 기둥(연간→연지→월간→월지→일지→시간→시지): 연주 → 3~5살 연상, 월주 → 또래(±1), 일지 → 동갑/1살, 시주 → 2~4살 연하. 없으면 남성 연하, 여성 연상.

## 6. 사주 엔진 (prototype 내 `SAJU` 모듈 + 주변 함수)
- 일주 `(jdn+49)%60`
- 연주: 입춘 정확 시각 기준 / 월주: `JEOL_T` 612개(1959–2009, KST 분), `jeolAt()`
- 시주: `sijin()` 30분 이동, 23:30 이후는 다음날 일진
- `toKST()`: 1961-08-10 이전 +8:30 → KST 보정, `KR_TZ` 서머타임(1960, 1987, 1988). 보정 시 인트로에 안내 문장
- `lunar2solar()`: `LUNAR` 표(1959–2008), 18,250일 검증 오차 0
- `analyze(P, male, queer)`: 오행 개수, 신강/신약 비율(월지3·일지2·나머지1), 격(월지 본기 십성), loveState(none/clean/mixed/many/sharp), 원국 합·충, 결핍/과다, yearGood
- `doors()`: 2026년 월별 신호 점수 → 너의 올해 장면 / `december()`: 12/8–12/24 일진 점수 → A/B, best day, shake day
- 문구 표: TXT, RES, WHY, ORN, PARTNER, READ, HEARD, HEARD_LOVE, WORRY, WORK_PLACE, WORK_LINE, FREQ, JEOL_NAME, SIJIN_IMG, GAN_COLOR, JI_ANIMAL, TXT.story
