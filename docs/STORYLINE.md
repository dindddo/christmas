# 스토리라인 v3 초안 (2026-11-22)

컷(`docs/SHOT_LIST.md`)은 이 스토리라인의 장면을 그린 것이다. 대사는 `content/`의 현재 문구를 그대로 쓰고, **[새]** 표시만 새로 제안하는 것.

## 로그라인

> 크리스마스마다 단 한 사람에게 인연을 선물해 온 천사 노엘. 올해 고른 사람은, 문 앞을 몇 번이나 그냥 지나친 너.
> 네 운명의 상대를 보여줘야 하는데 — 보여줄수록, 노엘이 먼저 흔들린다.

## 감정 장치

- **거리 사다리**: 장면이 갈수록 노엘과의 거리가 한 칸씩 줄어든다(멀리 → 테이블 건너편 → 옆 → 닿기 직전). 거리는 절대 뒤로 가지 않는다.
- **멈춤 규칙 [새]**: 노엘은 닿기 직전에 멈춘다(천사의 규칙). 설렘의 정점은 "닿음"이 아니라 "멈춤". 수위를 올려도 이 선은 지킨다 → 광고·심사 리스크도 줄어듦.
- **정보 → 노엘 반응 교차**: 사주 정보(판결·연도·달력·운명)가 나올 때마다 바로 뒤에 노엘의 흔들림 한 장면. 정보만 이어지면 감정이 식는다.
- **약속과 회수**: 결제 직전 "흔들렸던 이유 + 꼭 하고 싶었던 말" → 2막 1장과 마지막 편지에서 지킨다(현재 content 그대로).

## 구멍(지금 이야기에서 비는 곳)과 제안

1. **수위가 올라가는 이유가 없다.** 노엘은 너를 운명의 상대에게 보내는 역할인데, 왜 입맞춤 직전까지 가는지 설명이 없음 → **멈춤 규칙**(천사는 인간에게 닿으면 안 됨)을 넣으면 "가까워지지만 끝내 멈추는" 이유가 생기고, 정점(31)이 더 아프다.
2. **너의 정체가 흐리다.** 프롤로그 P7이 "퇴근길"인데 문 안에선 미니 원피스 → **퇴근길 직장인 + 오피스 원피스 + 코트**로 묶으면 옷이 자연스럽다.
3. **1막 중반(26 별자리·달력)에 노엘 장면이 없다.** 정보가 연달아 나와 감정이 식는 구간 → 날개 탭(25)을 달력 직후로 옮기거나, 달력 옆에 노엘 한 컷 추가.
4. **2막에 이미지가 하나도 없다.** 결제한 사람이 보는 곳인데 텍스트뿐 → 챕터 표지 5장 + 편지 1장 추가 제안. `wing_wrap`(날개로 감싸 안기)은 마지막 편지 장면으로 재활용 가능.
5. **자리 없는 컷**: `two_scarf`는 25~27 사이(거리 ④ 단계)에 넣을 수 있음, `hand_hold`는 편지 직후.
